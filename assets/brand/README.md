# Volve brand assets

Approved Volve Solutions logo assets for websites, reports, favicons, app icons and other branded projects.

## Files

- `volve-symbol.svg` — primary warm-slate symbol on a transparent background.
- `volve-symbol-reversed.svg` — pale-ochre symbol for dark backgrounds.
- `volve-symbol-on-slate.svg` — square favicon and app-icon treatment.
- `brand.json` — colours, construction rules, accessibility details and usage restrictions.

## Website use

Prefer SVG for all normal website placements. Use the symbol by itself and give a linked homepage logo the accessible label `Volve Solutions home`.

Raw asset URL pattern:

```text
https://raw.githubusercontent.com/Hugh-D/volve-os/main/assets/brand/[filename]
```

Do not join the two elements, round the V's upper-left terminal, close the negative-space channel or add effects.
