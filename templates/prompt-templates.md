# Prompt Templates

Reusable openers for common tasks. Copy, fill in the brackets, and go.

---

## Advisory Board Session

```
Convene the Volve Advisory Board.

[Optional: focus on these advisors only: Strategist, Skeptic, Founder, Revenue Advisor]

Here is my decision / challenge:

[Describe the situation. Include relevant context, constraints, and what you're trying to decide.]
```

---

## Coding Session Opener

```
Apply Volve coding standards for this session.
Think before coding, keep it simple, make surgical changes only, confirm the plan before executing.
I am not a coder — explain what you're doing in plain English.

Project context: [paste from relevant projects/ file or describe briefly]

Task: [describe exactly what you want built or fixed]
```

---

## Writing Task

```
Apply the Volve writing style guide for this task.
Active voice, no em-dashes, no AI filler, direct and frank.

Task: [email / document / coaching note / other]
Recipient: [who is this for]
Purpose: [what do you want them to think, feel, or do after reading it]
Key points to cover: [list them]
Tone notes: [any specific tone direction for this person]
```

---

## New Project Setup

```
I am starting a new project. Help me create a project context file for the Volve OS /projects folder.

Here is what I know so far:
[Describe the project — what it is, who it's for, current status, goals]

Use the _template.md structure and fill in as much as you can from what I've told you. Flag anything you need more information on.
```

---

## Decision Log Entry

```
I just made a decision. Help me log it clearly.

Decision: [what was decided]
Context: [why this decision came up]
Options considered: [what else was on the table]
Reasoning: [why this option was chosen]
Risks accepted: [what could go wrong]
Next actions: [what happens now]
```

---

## Brainstorm Session

```
I want to think through [topic / problem / opportunity].

My current thinking: [where you are now]
What I'm trying to figure out: [the question]
Constraints: [what's fixed, what's flexible]

Push back on my assumptions. Give me angles I haven't considered. Be direct.
```
